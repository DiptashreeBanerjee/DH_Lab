Assignments

Assignment 01

Romanized Bengali and Hindi Stopwords

Abstract. In NLP a stopword is the word that is removed while preprocessing. The project revolves around a bunch of Romanized Bengali and Hindi Stopwords wherein an attempt is made to uphold the diversity and nuances of the languages. Through this, a collection of stopwords is built which can be used for the analysis of Romanized Bengali and Hindi words.

The collection contains 103 Romanized Bengali Stopwords and 167 Romanized Hindi Stopwords. The stopword collection can be downloaded individually through the json files or an user can simply copy the code from the .py file and modify it to analyse whether there are duplicates in the list or not. The most prominent limitation of the project can be the words which exist in the English vocabulary as well, e.g., words like "jar" and "tar" which holds an independent meaning in itself.

Assignment 02

Extracting Indian Flora and Fauna through RAG

Abstract. This project revolves around five Indian novels as its corpus. It attempts to extract the names of Indian flora and fauna through the usage of the RAG pipeline which is done by the usage of LM Studio and Anything LLM.

The project emphasizes on the need for human intervention in the workflow of a machine-oriented task and thereby, poses the question: to what extent humans can be dependent upon local LLM? The selection of the books for the task was done in accordance to the aim of the task of extracting flora and fauna.

There were quite a number of limitation while building the project. The most crucial being the model’s poor performance in accordance to the configuration of the widely used laptops while there were also times when the results were not in accordance to the prompt provided.

Assignment 03

Synthetic Reading of a Short Story

Abstract. A synthetic reading attempts to bridge the gap between close reading and distant reading.This assignment is based upon the short story 'A Face in the Dark' by Ruskin Bond. It attempts to answer the research question through the extensive usage of the method- Synthetic Reading.

The initial reading of the text and the results generated through the code are compared and interpreted highlighting the difference of the two. The reading provides an insight as to how the LLM can be employed effectively for the interpretation of a literary text along with appropriate human intervention.

The main limitation of the project was the text chosen. Since, the number of words in the text was not humongous, the division into sections is a bit skewed. The project can thereby be said to be a preliminary level work.

View this project’s GitHub repository Assignment webpage

Assignment 04

Creating SKILL for LLM

Abstract. The project revolves around the creation of SKILL for the usage of LLM which can be deployed to find the books related to various performing arts.

The skill file features the countries and various fields of performing arts like dance, theatre. The speciality of the skill is that it never returns anything false as it cross verifies every book and then comes to a conclusion.

The fellow researchers or performance study enthusiasts accessing the Skill file can thus, easily customise and get the results according to their preference without frantically searching the web. The accessing of the Github repository by the user is encouraged to get a vivid knowledge about the developed skill.

Portfolio reflection

Throughout the four assignments two things remained constant : (a) The contentment of getting to explore new paths of creativity and embedding my culture and interests in it and (b) the challenge of using technology effectively while exploring the "Digital" part of my degree.

However, combatting the latter made me realise the importance of the human in the loop. Even though the AI is often claimed to be our next future, a human is needed to execute and interpret the results it generates. This assignment would have been impossible without the constant support of a few of my classmates and especially our TA Mr.Sourav Ghosh and our professor Dr.Shanmugapriya T.

Optional: methods note

The workflow of the project was more like solving a jigsaw puzzzle wherein the complete structures where given and we had to fit in our ideas in it.The skill assignment provided us with the entire flexibility as in what to use and how to develop it, the others somehow kept me restricted to the workflow.
